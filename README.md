# Library OOP Mini

Project sederhana PHP OOP untuk simulasi perpustakaan.

## Fitur

- Membuat object Book
- Membuat object Member
- Menampilkan informasi buku
- Menampilkan informasi member
- Simulasi peminjaman buku
- Inheritance menggunakan DigitalBook

## Struktur File

- Book.php : class untuk data buku
- Member.php : class untuk data member
- DigitalBook.php : class turunan dari Book
- index.php : menjalankan program

## Konsep OOP

Project ini menggunakan beberapa konsep PHP OOP:

- Class
- Object
- Property
- Method
- Constructor
- `$this`
- Visibility
- Encapsulation
- Inheritance
